# Final release checklist

- [ ] `npm install` completes in a networked environment
- [ ] `npm run build` succeeds with zero TypeScript/Vite errors
- [ ] PDF/image/text imports work offline after first load
- [ ] Document autosave, undo and redo work
- [ ] Two-column tablet layout and A4 print preview are checked
- [ ] AI endpoint is configured server-side; no provider secret is in frontend
- [ ] AI output is validated before being saved as document blocks
- [ ] Revision questions can be generated from stored notes
- [ ] Correct/incorrect answers update local statistics and weak-topic records
- [ ] Library search, sort and favorites behave correctly
- [ ] JSON backup downloads successfully
- [ ] PWA install/offline behavior is tested on Android and desktop
- [ ] Large PDFs and multi-image sources are tested
- [ ] GitHub production branch is tagged for release
